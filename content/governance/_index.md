CollabAtlas is governed by an editorial board model with automated quality checks. This ensures content remains reliable, accurate, and up-to-date.

## Roles

- **Core maintainers** — Own the repository, merge PRs, set strategic direction
- **Domain editors** — Review contributions in their area, ensure quality and accuracy
- **Contributors** — Anyone can submit via GitHub PR following our contribution guidelines

## Quality Pipeline

1. **Automated checks** on every PR: schema validation, taxonomy verification, link checking
2. **Editorial review** by the relevant domain editor
3. **Monthly freshness reports** flag entries not reviewed in 12+ months

See the [editorial board](/governance/editorial-board/) and [review process](/governance/review-process/) for details.
