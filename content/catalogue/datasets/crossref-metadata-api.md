Crossref Metadata API is a dataset for collaborative work. Scholarly metadata for over 130 million research outputs enabling citation and co-authorship analysis. It is particularly relevant in Social Sciences, Education and Publishing.

Crossref Metadata API supports open source and distributed collaboration and is suited for community-scale initiatives in remote settings.

Crossref Metadata API is a well-documented dataset with extensive evidence, guides, and community support.
