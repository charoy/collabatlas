ORCID Public Data File is a dataset for collaborative work. Annual data dump of researcher identifiers and affiliations enabling analysis of scientific collaboration networks. It is particularly relevant in Social Sciences, Education and Publishing.

ORCID Public Data File supports open source and distributed collaboration and is suited for community-scale initiatives in remote settings.

ORCID Public Data File is a well-documented dataset with extensive evidence, guides, and community support.
