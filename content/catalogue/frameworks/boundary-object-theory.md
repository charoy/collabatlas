Boundary Object Theory is a framework for collaborative work. Framework explaining how shared artifacts enable coordination across diverse communities of practice. It is particularly relevant in Social Sciences, Design and Software Engineering.

Boundary Object Theory supports interdisciplinary and co-production collaboration and is suited for small teams, organizational settings and multi-organization networks in in-person, remote and hybrid settings.

Boundary Object Theory is classified as a well-documented framework, indicating broad adoption and available documentation.
